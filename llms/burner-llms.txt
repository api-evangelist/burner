# Burner

> Burner is the original second phone number app for privacy protection, communication management, and creating multiple phone numbers from one device.

Burner is developed by Ad Hoc Labs and helps users protect their privacy, organize different areas of life, and maintain communication boundaries through voice calls, SMS, and MMS. Available on iOS and Android, Burner provides temporary and permanent phone numbers without requiring additional hardware or SIM cards.

## Main website
- https://www.burnerapp.com/

## Overview
- Burner is a second phone number app
- Burner is a privacy-focused communication tool
- Burner supports voice calls, SMS, and MMS
- Burner allows users to manage multiple phone numbers on one device
- Burner offers temporary and permanent phone numbers
- Burner helps users avoid sharing their primary phone number

## Core value proposition
- create multiple phone numbers for different life contexts
- protect privacy while dating, selling online, job hunting, traveling, or managing side projects
- burn numbers instantly when they are no longer needed
- maintain control over communication boundaries and personal anonymity
- separate personal, professional, and temporary conversations

## Key features

### Communication capabilities
- unlimited calls, texts, and picture messaging (MMS) within subscription plans
- VoIP and PSTN calling
- voicemail with AI-powered transcription and sorting on supported premium plans
- auto-reply functionality for automated responses
- video messaging on supported premium plans
- send and receive audio messages on supported premium plans
- free phone line swap
- multiple lines on one account
- Do Not Disturb mode with customizable quiet hours
- contact management and organization tools

### Privacy & security
- PIN lock protection for app access
- spam and robocall blocking via Nomorobo integration
- VPN for anonymous browsing and tracker blocking on supported premium plans across phone, Mac, and Windows
- number lookup capabilities on supported premium plans
- complete number deletion through burning
- no ads in any subscription tier

## Technology & architecture

### Platform availability
- iOS: full feature support for iPhone and iPad
- Android: full feature support for phones and tablets
- Web: limited management capabilities
- geographic availability: United States and Canada only, not available in Puerto Rico

### Technical implementation
- VoIP and PSTN technology for call routing and messaging
- OAuth 2.0 authentication for API access and third-party integrations
- webhook system for real-time event notifications
- RESTful API for programmatic access to line management, messaging, and configuration
- end-to-end encryption for sensitive communications

### Developer resources
- Burner API for programmatic access to user- and line-level features
- Burner App Starter Kit (BASK), an open-source React and Node.js framework for building Burner-integrated applications
- GitHub repository: https://github.com/adhoclabs/burner-app-starter-kit
- developer documentation with OAuth 2.0 guides, webhook examples, and API references

## Important limitations & constraints
- Burner numbers cannot dial 911 or be used for emergency services
- support for SMS shortcode services is limited
- geographic availability is limited to the United States and Canada
- international calling is not supported
- inactive numbers may be recycled after expiration
- calls may use cellular minutes through a relay system and are not purely data-based
